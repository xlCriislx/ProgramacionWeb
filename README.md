# Conversor de Divisas 💱

Este es un proyecto de conversión de divisas que permite a los usuarios calcular el valor de una cantidad en diferentes monedas utilizando las tasas de cambio actuales. La aplicación está diseñada con una interfaz visualmente atractiva y responsiva, que incluye un fondo personalizado con un diseño semi-transparente.

## 🚀 Características

- **Conversión de Divisas en Tiempo Real**: Obtiene tasas de cambio actualizadas desde una API.
- **Validación de Formularios**: Asegura que los campos de entrada sean correctos antes de procesar.
- **Manipulación del DOM**: Actualización dinámica de los valores convertidos en la interfaz.
- **Interfaz Visualmente Atractiva**: Utiliza un diseño semi-transparente sobre un fondo personalizado.
- **Animaciones Interactivas**: Botones y elementos con efectos al pasar el cursor.
- **Despliegue Serverless**: Optimizado para desplegarse en Azure Blob Storage.

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura y contenido del sitio web.
- **CSS3**: Estilos personalizados y diseño responsivo.
- **JavaScript (ES6)**: Lógica del cliente y manejo de la API.
- **ExchangeRate API**: API gratuita para obtener las tasas de cambio.
- **Azure Blob Storage**: Despliegue de la aplicación como sitio estático.
